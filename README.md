# Muhammad Nur Azam | HR Portfolio

A professional personal portfolio website for Muhammad Nur Azam, an HR professional focused on talent acquisition, employee relations, HR operations, and HR compliance.

## Technologies used
- HTML5
- CSS3
- JavaScript (ES modules)
- Tailwind CSS via CDN
- Lucide icons via CDN
- Node.js static server for local preview only

## Project overview
This portfolio is designed as a clean, modern, credible professional brand site for LinkedIn and recruiter use. It includes sections for:
- About / hero
- Career journey
- Key achievements
- Selected work
- HR Journal
- Expertise
- Resume
- Contact / LinkedIn

## Local development
From the project root, run:

```powershell
& "C:\Program Files\nodejs\node.exe" server.js
```

Then open:

```text
http://127.0.0.1:3000/
```

## GitHub Pages deployment
This project is already compatible with GitHub Pages because it is a static site using relative asset paths and does not require a build process.

This repository is configured for the GitHub Pages user-site root domain:

```text
https://nurazam190.github.io/
```

The repository name matches the required user-site pattern:

